# DigitalHuman

数字人操控项目，包含后端、前端和数据库建表脚本。

## 项目结构

- `backend/`：Spring Boot 后端服务
- `frontend/`：React 前端应用
- `database/`：MySQL 数据库初始化脚本

## 数据库

数据库脚本位于：

```text
database/Mysql数据库账户建表.sql
```

## 后端启动

```bash
cd backend
mvn spring-boot:run
```

## 前端启动

```bash
cd frontend
npm install
npm start
```
